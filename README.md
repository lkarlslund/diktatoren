# Diktatoren

On-demand dictation for the desktop. Wake it with a wake word or a hotkey, talk into the
input box, fix the text with your voice, then insert it into the window you were working in,
copy it to the clipboard, or throw it away.

Speech recognition, voice activity detection and wake-word detection run locally through
[audio.cpp](https://github.com/lkarlslund/audio.cpp). Nothing leaves your machine.

Runs on Windows, macOS and Linux (Wayland and X11). Lives in the system tray.

Status: under construction.
